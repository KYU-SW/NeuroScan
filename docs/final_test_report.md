# NeuroScan v1 고정 내부 평가 보고서

> 연구 및 교육 목적의 프로토타입이며, 임상 사용이 승인된 의료기기가 아닙니다. 이 보고서의 수치는 공개 연구
> 데이터(ISLES 2022)의 고정 내부 평가 세트에 대한 결과이며 **임상 성능을 의미하지 않습니다.**

**평가 명칭:** 동결된 NeuroScan v1의 고정 내부 평가 세트 최초 성능 평가

평가 방법은 실행 전에 [`docs/final_test_protocol.md`](final_test_protocol.md)와
[`configs/final_test_v1.yaml`](../configs/final_test_v1.yaml)로 사전 등록했고, 그 절차를 바꾸지 않고 1회 실행했다.
이 문서에는 집계 결과만 싣는다. 환자별 결과·예측·QA 이미지는 로컬 `results/final_test/v1/`에만 있다(Git 제외).

**Test Ground Truth의 과거 사용:** Test Ground Truth는 과거 데이터 분할 층화와 재구성·원본 공간 복원 엔진 검증에
제한적으로 사용되었으나, Test Prediction 생성, 모델 선택, Threshold 조정, 후처리 선택 또는 성능 기반 정책 결정에는
사용되지 않았다. 따라서 이 평가는 성능 기반 결정에 쓰이지 않은 **고정 내부 평가 세트**의 최초 평가로 기술한다.

## 8. 해석과 제한

- **단일 seed 공식 run:** 모델별 학습 1회의 결과이며, seed 변동 폭은 측정하지 않았다. 0.01 수준의 차이는 seed
  변동과 구분하기 어렵다.
- **Validation 개선의 비재현:** 2.5D의 Validation 개선(+0.012)이 고정 내부 평가에서 재현되지 않았다. 인접 slice
  입력만으로 일관된 성능 개선이 보장되지는 않는다.
- **강도 augmentation (R1):** 2.5D에서 강도 augmentation이 같은 modality의 z−1/z/z+1 채널에 독립적으로 적용됐을
  가능성이 있어 2.5D의 이점이 과소평가됐을 수 있다(공식 비교에서는 수정하지 않음).
- **Thick slice:** thick slice 그룹(n = 8)에서 2.5D 저하 경향(−0.034)이 보였다. 인접 slice 간격이 넓으면 문맥 정보가
  약할 수 있으나 표본이 작아 기술적 관찰에 그친다.
- **ADC 단위별 차이:** ADC 저장 단위 그룹별로 차이의 방향이 달랐다(+0.035 / −0.028 / −0.014). 기관·장비 차이와
  얽혀 있을 수 있다.
- **Negative 1명:** 병변 없는 영상의 위양성 경향은 판단할 수 없다.
- **기관 정보 없음:** 기관별 분석 불가.
- **외부 검증 미수행:** 다른 기관·장비·프로토콜에 대한 일반화는 확인되지 않았다.
- **Test GT의 과거 제한적 사용:** 위 고지 참조.
- **의료기기 아님:** 이 결과는 연구용 프로토타입의 공개 데이터 내부 평가이며 임상 성능을 의미하지 않는다.
