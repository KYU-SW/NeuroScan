# NeuroScan v1 실패 사례 정성 분석 요약

> 연구 및 교육 목적의 프로토타입이며, 임상 사용이 승인된 의료기기가 아닙니다.
> 이 문서는 고정 내부 평가 이후의 **사후 기술적 분석** 요약입니다. 의료적 진단 문서가 아니며 Ground Truth의 옳고
> 그름을 판단하지 않고, v1 모델이나 평가 결과를 변경하지 않습니다. 목적은 NeuroScan v2에서 검증할 수 있는 가설
> 후보를 정리하는 것입니다. 모든 수치는 익명 집계이며 사례별 자료는 포함하지 않습니다.

## 1. 관련 문서

- [docs/final_test_report.md](final_test_report.md) — v1 고정 내부 평가 결과(공식 성능 수치는 이 문서만 따른다)
- [docs/failure_analysis_protocol.md](failure_analysis_protocol.md) — 사례 선정 규칙, 분석 기준, 출력·감사·공개 범위

## 2. 분석 범위

고정 내부 평가 결과표에서 사전 규칙으로 사례를 선정했다(규칙: 프로토콜 §2).

| 그룹 | 규칙 | 사례 수 |
|---|---|---|
| F | 2D 또는 2.5D Dice < 0.50 (병변 있는 사례) | 4 |
| Z | 2.5D Dice = 0 | 1 |
| I | Dice 차이(2.5D − 2D) 상위 3 | 3 |
| W | Dice 차이 하위 3 | 3 |
| N | 병변 없는 사례 | 1 |
| G | 두 모델 모두 Dice ≥ 0.85, thin·thick 대표 각 1 | 2 |

그룹 사이 중복을 제거하면 **10건**이며, 10건 모두 분석을 완료했다(중단 0건).

## 3. 분석 절차

1. **Metrics-only 단계**: 결과표만 읽어 사례 선정, 로컬 alias 부여, 수치 기반 분류(T1–T3, T8 후보).
2. **승인된 영상 기반 단계**: 명시적 승인 문구로 1회 실행. 선정 사례의 영상과 저장된 예측만 읽어 TP·FP·FN 차이
   지도, 모델 간 차이 지도, component·matching, 거리, 신호 요약, QA 그림을 만들고 T1–T9를 판정했다.
3. **사용자 contact sheet 육안 QA**: 최종 판정 **PASS WITH NOTE**. 영상·overlay·정렬·색상·범례·개인정보 기준은
   통과했다. Panel C 아래쪽 행 첫 번째 제목이 위 그림과 일부 겹치는 경미한 표시상 제한이 있으나 분석 내용에는
   영향이 없었다.

## 4. 접근 및 생성 규모

| 항목 | 값 |
|---|---|
| 사례당 접근 파일 | DWI, ADC, GT, 2D 예측, 2.5D 예측 |
| 총 파일 접근 | 50회 (선정되지 않은 사례 접근 0) |
| 모델 추론 / probability map 생성 | 0 / 0 |
| 차이 지도 | 30개 |
| QA 그림 | 86장 |
| Contact sheet | 12장 |

생성 자료는 모두 로컬 전용이며 저장소에 포함하지 않는다.

## 5. 유형 분류 집계 (T1–T9)

T1–T8은 병변 있는 9건, T9는 전체 10건 기준이다. 분류는 측정 규칙의 결과이며 원인을 뜻하지 않는다.

| 코드 | 내용 | 2D | 2.5D |
|---|---|---|---|
| T1 | 과소 분할 | 3 | 2 |
| T2 | 과대 분할 | 1 | 1 |
| T3 | 위치 불일치 | 1 | 1 |
| T4 | 작은 GT component(< 0.1 mL) 놓침 | 2 | 2 |
| T5 | GT에서 10 mm 넘게 떨어진 FP component | 7 | 7 |
| T6 | 경계 불일치 검토 후보 | 6 | 6 |
| T7 | 분할·병합 차이 | 2 | 1 |
| T8 | 모델 간 문맥 차이 검토 후보 (사례 단위) | 2건 | |
| T9 | 영상 신호 추가 검토 후보 | 3 | 6 |

T6와 T9는 **판별력이 낮을 수 있는 검토 후보** 규칙이며, 실제로 다수 사례에서 표시되었다.

## 7. 공통 관찰 (2D·2.5D)

- 실패 그룹(F) 4건은 모두 thin slice였고, 그중 3건은 1 mL 미만 병변이었다.
- 두 모델 모두 GT와 겹치지 않는 예측 component(prediction_only)가 많았다.
- GT에서 10 mm 넘게 떨어진 FP component가 병변 있는 사례 다수에서 관찰되었다.
- FP·FN이 GT 경계 2 mm 이내에 집중된 검토 후보가 다수였다.
- FP·FN 영역의 DWI z-score가 뇌 기준 영역보다 높게 나타나는 경향이 있었다. 다만 이를 표시하는 T9 규칙의 판별력은
  제한적일 수 있다.

## 8. 2.5D 개선 그룹 (I, 3건)

- 3건 모두 thin slice, 1 mL 미만 병변이었다.
- 3건 모두 2.5D에서 예측 component 수가 줄었고, GT에서 멀리 떨어진 FP component도 줄었다.
- 일부 사례에서 관찰된 패턴이며, 작은 병변 전체에 일반화하지 않는다.

## 9. 2.5D 악화 그룹 (W, 3건)

- 3건의 양상이 서로 달랐다: FP component 증가, FN 발생, GT와의 겹침 없음.
- 하나의 공통 실패 원인으로 묶을 수 없다.

## 10. Thick / Thin slice 관찰

- 분석 대상 중 thick slice 사례는 2건이었다.
- 두 사례 모두 2.5D에서 예측 component 수와 GT에서 멀리 떨어진 FP component가 늘었다.
- n = 2이므로 가설 수준으로만 기록한다.

## 11. ADC 단위 관찰

- ADC 1e−6 단위 그룹 2건은 thick slice 2건과 같은 사례였다. 따라서 ADC 단위와 slice 두께의 영향을 분리할 수 없다.
- 다른 ADC 단위 그룹에서는 일관된 패턴을 확인하지 못했다.

## 12. Negative 사례

- 병변 없는 사례는 1건뿐이다. 두 모델 모두 극소량의 FP 예측이 있었다.
- 일반적인 negative 성능을 주장할 수 없다. 수치는 [고정 내부 평가 보고서](final_test_report.md) §4를 참조한다.

## 13. v2 가설 후보

관찰은 측정된 집계이며, 아래 가설은 검증 대상일 뿐 확인된 사실이 아니다. 확신 수준은 `possible` 또는
`undetermined`로만 표기한다.

| # | 관찰 | 가설 후보 | 대안 설명 | 검증 방법 | 확신 수준 |
|---|---|---|---|---|---|
| 1 | thick slice 2건에서 2.5D의 예측 component와 떨어진 FP 증가 | thick slice에서 고정 z±1 context가 떨어진 예측 component를 늘릴 가능성 | 단일 seed 변동, 채널별 독립 강도 augmentation(Phase 4 문서의 한계 항목), ADC 단위·기관 차이와의 혼재 | 다중 seed, thick slice 외부 데이터, slice 간격에 따른 context 정책 실험, modality-consistent augmentation ablation | undetermined |
| 2 | 개선 그룹 3건(thin, 1 mL 미만)에서 2.5D의 떨어진 FP 감소 | thin slice의 일부 작은 병변에서 2.5D 문맥이 떨어진 FP component를 줄일 가능성 | 사례 선정 효과(상위 개선 사례만 선택), seed 변동 | 작은 병변을 따로 나눈 외부 평가, 다중 seed | possible |
| 3 | 실패 그룹 4건 중 3건이 1 mL 미만, T4·T5 표시 다수 | 1 mL 미만 병변에서 sensitivity와 FP 사이의 균형 문제가 존재할 가능성 | 원본 공간 복원 시 1–2 voxel component 손실(Phase 2 한계), 주석 경계 변동 | 병변 크기별 subgroup이 충분한 외부 데이터, 크기별 오류 분석 | possible |
| 4 | FP·FN 영역 DWI z-score가 뇌 기준 영역보다 높은 경향 | 모델이 DWI 고신호 영역에 반응할 가능성 | GT 범위 밖의 신호 변화, 인공물, case별 정규화 범위 | 독립 육안 검토, 신호 범위별 오류 분석, 외부 데이터의 신호 분포 비교 | undetermined |
| 5 | GT 경계 2 mm 이내 오류 집중 후보 다수 | GT 경계 주변 오류에 모델 경계 추정과 주석 경계 변동이 혼재했을 가능성 | 해상도·resampling 효과, 경계 규칙(T6)의 낮은 판별력 | 관찰자 간 변동 정보가 있는 데이터, 경계 거리별 오류 분포 | undetermined |

이 가설들은 v1을 수정하는 근거가 아니며, v2 실험 설계와 외부 데이터 요구조건
([docs/external_dataset_requirements.md](external_dataset_requirements.md))에만 사용한다.

## 14. 확정할 수 없는 부분과 한계

- 사후 선정된 10건의 정성 분석이며 일반화할 수 없다.
- 단일 seed 모델이라 seed 변동의 영향을 알 수 없다.
- probability map이 없어 threshold 근처의 행동을 분석할 수 없다.
- 원인과 인과관계를 확정할 수 없다.
- thick slice와 ADC 단위가 같은 사례에 겹쳐 효과를 분리할 수 없다.
- 기관 정보가 없어 기관별 차이를 볼 수 없다.
- T6·T9 규칙의 판별력이 제한적이다.
- 신호 패턴이나 오류의 의료적 의미는 판단하지 않는다.
- 이 평가 세트는 이미 평가와 분석에 사용되었으므로 v2의 독립 평가에는 새로운 데이터가 필요하다.
